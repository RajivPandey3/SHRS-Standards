# Reviews Directory

This directory stores formal governance audits, architectural reviews, and peer feedback files.

## Naming Convention
To maintain a scalable and traceable structure, review files SHALL follow this convention:
- **Audits**: `AUDIT-[NN].md` (e.g., `AUDIT-01.md`, `AUDIT-02.md`)
- **Release Candidate Reviews**: `RC[N]-REVIEW.md` (e.g., `RC1-REVIEW.md`)
- **General Reviews**: `REV-[DATE]-[TOPIC].md`
