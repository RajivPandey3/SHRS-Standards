# Welcome to the SHRS Standards Repository

This is the canonical home of the SHRS standards and governance frameworks.

## Available Standards

- **[SGM - Standards Governance Model](standards/SGM/index.md)**: The foundational governance architecture for the repository.
- **[SEG - Standards Editorial Guide](standards/SEG/index.md)**: The mandatory style guide for language, formatting, and structural design across all standards.
- **[SAO - Standards Authoring Operations](standards/SAO/index.md)**: The operational procedures, Git workflows, and technical steps for authoring documentation.
- **[KPM - Knowledge Package Publication Model](standards/KPM/chapters/publication.md)**: The canonical framework for publishing Knowledge Packages.

## About
This documentation site serves as a Triple-A (AAA) repository ensuring strict traceability, compliance, and governance across all knowledge assets. 
All documents strictly follow the canonical Editorial Style Guide.
