# Annex C: AI Vendor Mapping

**Status:** Approved  
**Scope:** SHRS Ecosystem  

## 1. Current Authority Mapping
While the SHRS architecture uses vendor-neutral terms for its AI workflows, the current real-world mappings (as of the v1.0 foundation) are as follows:

- **Architecture Authority:** Gemini (Agentic AI)
- **Implementation Authority:** Claude (e.g., Claude 3.5 Sonnet)
- **Review Authority / Validation Authority:** ChatGPT (e.g., GPT-4)

## 2. Rationale
By keeping the core standards (SAO, SEG) vendor-neutral, the SHRS ecosystem remains immune to the rapid changes in the AI landscape. If a new, superior model is released in the future, only this Annex needs to be updated, preserving the integrity of the canonical workflows.
