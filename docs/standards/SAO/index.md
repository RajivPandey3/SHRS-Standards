# Standards Authoring Operations (SAO)

**Edition:** 1  
**Status:** Working Draft (WD)  
**Authority:** Standards Maintainer (Transitional)  

The Standards Authoring Operations (SAO) defines the actual technical and operational workflows for authors contributing to the SHRS repository. While SGM sets the rules, SAO explains *how* to execute them using Git, Work Orders, and Change Requests.
