# Chapter 6: File Naming Conventions

## 6.1 Kebab-Case Rule
To ensure consistency across the repository and avoid issues across different operating systems, all repository filenames SHALL use `kebab-case`. 

**Allowed:**
- `feature-request.md`
- `file-naming.md`

**Not allowed:**
- `Feature_Request.md`
- `FeatureRequest.md`
- `feature_request.md`

By following this rule, future contributors will never introduce inconsistent naming patterns.
