# Standards Editorial Guide (SEG)

**Edition:** 1  
**Status:** Working Draft (WD)  
**Authority:** Standards Maintainer (Transitional)  

The Standards Editorial Guide (SEG) provides the mandatory rules for language, formatting, Markdown usage, and structural design across all SHRS standards. It ensures that every standard looks, reads, and functions consistently.
