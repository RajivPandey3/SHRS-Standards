# Release Notes

## Release Candidate 1 (v0.2.0)

### Release Scope
This release candidate stabilizes the SGM framework and brings it to 100/100 editorial and architectural compliance based on formal audits.

### New Features
- Full formal traceability via Work Orders and Requirement Registries.
- Extended Lifecycle States including "Maintained" and "Withdrawn".
- Integrated Governance Record Templates.

### Breaking Changes
- Governance model explicitly transitioned to "Standards Maintainer (Transitional)" role, overriding references to the "SHRS Governance Board".
- Chapter 5 and Chapter 6 have been swapped for logical continuity.

### Known Issues
- Real-world validation of Governance Gates via CI/CD pipelines is pending implementation.

### Next Milestone
- Baseline approval and formal issuance of Edition 1 (v1.0.0).
