# Requirement Registry

This registry aggregates normative requirements. For full traceability, please refer to [Annex F](../annexes/requirement-traceability-matrix.md).

- **REQ-001**: All changes MUST be traceable.
- **REQ-002**: Terms MUST be Capitalized as per the Glossary.
- **REQ-003**: All Publication Artifacts SHALL be derived exclusively from the Canonical Source.
