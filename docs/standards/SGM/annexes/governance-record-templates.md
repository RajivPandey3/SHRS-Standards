# Annex C — Governance Record Templates

## Status
**Draft**

This annex provides the mandatory templates for all Governance Records within the SHRS ecosystem. Any Governance Decision MUST be documented using one of these templates to ensure Traceability.

## C.1 Work Order Template
```markdown
**Work Order ID:** WO-[ID]
**Title:** [Short Description]
**Initiated By:** [Standards Maintainer Name]
**Date:** YYYY-MM-DD
**Objective:** [Describe the intended modifications]
**Approval Authority:** [Name/Role]
```

## C.2 Change Request Template
```markdown
**CR ID:** CR-[ID]
**Target Standard:** [Name & Version]
**Proposed Change:** [Details]
**Reason:** [Justification]
**Status:** [Pending/Approved/Rejected]
```
