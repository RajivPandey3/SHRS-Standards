# Annex D — Lifecycle Examples

## Status
**Draft**

This annex provides illustrative examples of how a Standard moves through its Lifecycle States.

## D.1 Example: Minor Revision
1. **Draft**: The Standards Maintainer drafts a correction for a typo.
2. **Under Review**: A Work Order is submitted to the Approval Authority.
3. **Approved**: The Approval Authority issues a Governance Decision to accept the fix.
4. **Published**: A new Version is published as a formal Corrigendum, generating new Publication Artifacts.
