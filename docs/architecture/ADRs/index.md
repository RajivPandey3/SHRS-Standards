# Architecture Decision Records (ADRs)

An Architecture Decision Record (ADR) is a short text file in a format similar to an Alexandrian pattern that captures an important architectural decision made along with its context and consequences.

**Governance Rule:** Nothing important should exist only in conversation. Every major decision SHALL produce an ADR.
